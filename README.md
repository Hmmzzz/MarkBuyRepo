# MarkBuy 热门订阅目录

这是 MarkBuy iOS 客户端使用的公开热门订阅数据和图标资源仓库，不包含应用源码、账号凭据或本地维护程序。

## 公开内容

- `subsrepo/subscriptions.json`：客户端读取的订阅模板目录。
- `subsicon/`：目录引用的 512×512 PNG 图标。
- `schemas/subscriptions.schema.json`：公开数据格式。

GitHub 是规范数据源；Gitee 镜像中的业务数据应与本仓库一致，仅图标 URL 前缀不同。

## 数据说明

订阅价格、套餐、地区和上架状态可能发生变化。目录内容仅用于帮助用户填写订阅记录，不构成销售报价，也不代表相关品牌的官方背书。使用前请以服务提供方当前公布的信息为准。

第三方名称、图标和商标归各自权利人所有。新增图标前必须确认来源和使用条件，详见 [`NOTICE.md`](NOTICE.md) 和 [`ASSETS.md`](ASSETS.md)。

## 提交候选

请使用“热门订阅候选”Issue，提供：

- 服务名称和官方网站；
- 官方产品或定价来源；
- 币种、计费周期、套餐名称和适用地区；
- App Store ID（如有）；
- 图标来源和必要说明。

候选不会自动发布。维护者会在本地完成核验和结构检查，只把审核后的目录及图标变更提交到公开仓库。

## 客户端兼容约束

- `id` 是稳定身份，修改 ID 等价于新增另一条订阅。
- `commonPrices` 第一项是卡片默认展示价格。
- 未知分类会被客户端降级为 `other`。
- 未知周期会被客户端降级为 `monthly`。
- `isBundle=true` 时必须包含 `bundledSubscriptions`。
- 客户端可能缓存远程目录，发布不会对所有设备瞬时生效。
